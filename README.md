# Simple Linear Regression

This project demonstrates **Simple Linear Regression** using Python.  
It shows how to build a linear regression model, train it on data, and visualize the results.

---

## 📌 Objective
- To understand the concept of Simple Linear Regression
- To predict output values based on a single input variable
- To visualize the relationship between independent and dependent variables

---

## 🛠 Tools & Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

---

## 📊 Description
Simple Linear Regression is a statistical method used to model the relationship between:
- **Independent Variable (X)**
- **Dependent Variable (Y)**  

The model follows the equation:
Y = mX + c
where  
- `m` = slope  
- `c` = intercept  

---

## 🚀 Steps Performed
1. Imported required libraries  
2. Loaded the dataset  
3. Visualized the data  
4. Trained the Linear Regression model  
5. Predicted results  
6. Plotted regression line  

---

## 📈 Output
- A trained linear regression model
- Graph showing best-fit line over data points
